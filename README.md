
# Bean & Basil Café Website

A responsive café website prototype developed for Future Interns Project 3: Local Business Website & Live Pitch.

## Features
- Responsive café landing page
- Interactive menu filtering
- Menu cards with sample prices
- Café story, opening hours, and contact section
- Reservation enquiry form with client-side validation
- Mobile-friendly navigation

## Technology
- React
- Vite
- CSS
- Lucide React

## Run Locally

Requirements: Node.js and npm.

```bash
npm install
npm run dev
```

Open the local URL printed in your terminal.

## Production Build

```bash
npm run build
```

## Important Notes
This is a demonstration prototype. The business details, menu items, prices, hours, and contact number are sample content. The reservation form displays a confirmation message but does not send or store real bookings.
