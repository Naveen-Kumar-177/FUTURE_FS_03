
# Future Interns — Project 3
## Bean & Basil Café Website

### 1. Project Overview
Bean & Basil is a responsive café website prototype designed to help a local restaurant or café present its brand, showcase menu items, share visitor information, and receive table enquiries.

### 2. Problem Statement
Small local cafés may rely on social media or word-of-mouth alone to communicate their menu, prices, opening hours, and location. Customers benefit from having this information presented in one accessible place.

### 3. Proposed Solution
A modern website that brings together café branding, menu categories, food photography, business information, and a reservation enquiry form.

### 4. Key Features
- Responsive layout for desktop and mobile devices
- Interactive menu category filters
- Menu cards with sample prices and descriptions
- Café story, location, hours, and contact sections
- Reservation enquiry form with browser-side validation
- Confirmation message for demonstration purposes

### 5. Technology Stack
- React for reusable UI components
- Vite for development and production builds
- CSS for layout, responsive design, and styling
- Lucide React for interface icons
- Git and GitHub for version control and project hosting

### 6. Target Users
- Local café and restaurant owners
- Customers looking for menu and business information
- Visitors who want to enquire about a table

### 7. Expected Benefits
- Clear presentation of the café's identity
- Easier access to menu and visitor information
- Better experience across different screen sizes
- A foundation for future online ordering and real reservations

### 8. Current Limitations
This prototype uses sample menu data, placeholder business details, and a client-side-only enquiry form. It does not save bookings, send emails, process payments, or verify table availability.

### 9. Future Enhancements
- Connect the enquiry form to a backend and database
- Send booking confirmation emails
- Add an admin dashboard for menu management
- Integrate Google Maps and real business details
- Add online ordering and payment integration

### 10. Conclusion
Bean & Basil demonstrates how a clean, responsive website can help a local café present its offerings and improve customer access to information. The prototype provides a foundation for a production-ready business website.
